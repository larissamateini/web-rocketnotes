# RocketNotes 🚀

O **RocketNotes** é uma aplicação web desenvolvida em React para o gerenciamento de notas pessoais. Com ele, o usuário pode organizar ideias, salvar links úteis e categorizar anotações através de tags, tudo em uma interface moderna e responsiva.

## <a id="project"></a>💻 Sobre o Projeto

## <a id="tech"></a>🛠 Tecnologias Utilizadas

- **[React](https://reactjs.org/)**: Biblioteca core para a interface.
- **[Vite](https://vitejs.dev/)**: Tooling de próxima geração para um desenvolvimento rápido.
- **[Styled Components](https://styled-components.com/)**: Para estilização e temas (CSS-in-JS).
- **[React Router Dom v6](https://reactrouter.com/)**: Navegação entre páginas.
- **[Axios](https://axios-http.com/)**: Para consumo de APIs externas.
- **[React Icons](https://react-icons.github.io/react-icons/)**: Conjunto de ícones para a interface.

## <a id="execute"></a>🚀 Como Executar

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina:
* [Node.js](https://nodejs.org/en/)
* Um gerenciador de pacotes como o [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/).

### Passo a passo

1. Clone o repositório.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o projeto em modo de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse no navegador.
